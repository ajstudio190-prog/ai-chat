What is ai-chat? (Explain Like I'm 5)

Imagine if your computer had a real software engineer living right in your terminal. When you tell it: "Close the Settings app" or "Open a new terminal window" or "What time is it in Kathmandu, Nepal?", it doesn't make excuses or guess wrong numbers. It uses real native macOS automation, checks true astronomical clocks, and does the job instantly on your screen.

Self-Healing ReAct Loop

If a tool or script fails, the agent observes the error and fixes its own syntax automatically—just like Antigravity.

Multi-Model Roster

Switch anytime between Llama 3.2, Qwen 2.5 Coder, Antigravity, Claude Code, and Codex using /model <name>.

Rule 2 & 3 Safety Shield

Zero chance of deleting system files or resetting repositories. All commands pass through an unbreakable AST safety gate.

Genesis & Autonomous Creation Story

The Problem: When running the local 3B model (llama3.2:3b), users noticed it hallucinated timezones and guessed wrong file paths like /Applications/Utilities/Settings.app. Why? Because 3B models lack the parameter volume for zero-shot OS scripting and had no feedback loop to recover from mistakes.

The AGY Secret: Antigravity (AGY) succeeds because it utilizes frontier models combined with a multi-turn observation loop: when an action fails, AGY reads the exact stderr and corrects itself immediately.

The Architecture Solution: We created core/agent_engine.py equipped with a 5-step ReAct observation loop, dynamic model escalation (/model), and deterministic macOS window and timezone control.
